代理路由规则
  • 生产地址:8080 下的 /api、/oauth、/sso、/login → 真实后端
  • 生产地址:8080 的其他请求 → 本地 dev server
  • 生产地址:8081 → 模拟 IdP，其他主机 → 直通

演示步骤

约 1 分钟
  1. 看本地代码 打开手机窗口（代理默认开启），页面显示 LOCAL DEV， 但地址栏仍是生产 origin。
  2. 走一遍 SSO 点「登录」→ 模拟 IdP → 回到 /callback?code=…。回调页仍来自本地， /oauth/token 已透传到生产后端。
  3. 切回生产 关闭代理开关（自动刷新），页面变为 PRODUCTION， 登录态还在——Cookie 一直写在同一个 origin 下。
  4. 体验热刷新 重新打开代理，编辑 web/local/app.js 里的 LOCAL_NOTE 并保存，手机页面会自动刷新。
会同时清掉手机 session 和服务端内存 session。
